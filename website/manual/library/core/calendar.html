Calendar

Appointments and events can link to the phone calendar. Coming Up is still the life timeline.

Nudge me Ready v3 · 0.3.1 · Menu → Calendar.

Download PDF All guides

Workflow

  1. Create an appointment or event.
  2. Optionally link it to the phone calendar from the item.
  3. Or tap Show my appointments here on Home.
  4. Open Calendar to see linked dated items.

Good to know

  • There is no second calendar engine.
