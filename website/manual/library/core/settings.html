Workflow

  1. Turn on Push so dated items can nudge the lock screen.
  2. Quiet hours hold alerts overnight.
  3. Daily summary names today’s real titles, or stays quiet if nothing is due.
  4. Security: password or PIN, optional Face ID, recovery email and recovery code.
  5. This is home saves a leaving-home place when you want that checklist.

Good to know

  • Forgetting a PIN resets the lock — it does not delete nudges. Uninstalling the app does.
