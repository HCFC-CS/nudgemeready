Workflow

  1. Open Nudges to see open items.
  2. Tap Later to move something to tomorrow.
  3. Tap Sorted when it is done — a small Reward Bank point may be added.
  4. Tap Smaller if it feels like too much.
  5. Tap Ask to send a message about that item from this phone.
  6. Filter with Open / All / Done, or Dates / To-dos / Lists. Search if the list is long.

Good to know

  • Skip, snooze and hard days never cost you anything in the app.
