Workflow

  1. Open Home after See my day.
  2. Read What’s coming up — the next dated item is shown first.
  3. Tap See what’s coming up for Today / 7 days / Month / later.
  4. Use Show my appointments here if you want phone calendar events on the same timeline.
  5. Focus on this starts a calm session on the next item.
  6. If the timeline is empty, tap Add something you don’t want to forget.

Good to know

  • No Ready4 pack is required.
  • Holidays and similar calendar noise are skipped.
