What this pack is for

Daily reset · Cleaning planner · Leaving-home check · Bin collection · Home maintenance · Bill reminders

How to find it

  1. Open Menu → Ready4Packs (or Home → Explore).
  2. Open Ready4 Home.
  3. Read the preview, then tap install. On TestFlight you will not be charged if billing is off.
  4. Editable items appear in Nudges and What’s coming up.

Everyday workflow

  1. Install the pack once.
  2. Open a template from Nudges and change the title, day or checklist to match your life.
  3. Use Later, Sorted, Smaller or Ask on the list.
  4. From Add, use the extra pack actions if you need a new item in this area.
  5. Open the pack planner (Home pack tile, or Menu if shown) for today / this week in this pack.
  6. Optional: turn on Push so dated items can nudge the lock screen.
