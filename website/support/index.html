Support

Email support@nudgemeready.app for help with Nudge me Ready.

Getting started

  • Open the app and set up Face ID, a PIN, or a password on the landing page (recommended).
  • Add a nudge from +nudge, or browse Notes, Reminders, Appointments, and Lists.
  • For appointments, add guests from Contacts and optionally link to your phone calendar.

Common questions

Why can’t I use Face ID / voice / calendar yet?

Those features need a full app install from TestFlight (or a development build), not Expo Go. Install the latest TestFlight build after each native update.

Where is my data stored?

On your phone. This version does not sync nudges to the cloud. Keep a recovery code if you turn on app lock.

How do Crew invites work?

Share the invite link from Invite Crew. The other person opens it on their phone with Nudge me Ready installed. The link carries the invite details so they can accept even if they never had the invite before.

I forgot my PIN or password

On the sign-in screen, choose Forgot PIN? / Forgot password? and confirm with Face ID / device passcode, or enter your recovery code.

Report a problem

Email support@nudgemeready.app with:

  • Your iPhone model and iOS version
  • What you were trying to do
  • A screenshot if helpful

We aim to reply within a few working days.
