# Nudge Me Ready Project Instructions

## Product purpose

Nudge Me Ready is a supportive reminder, routine and shared-care application.

## Product principles

- Never shame the user.
- Never use guilt-based language.
- Use warm, supportive and straightforward wording.
- Make all reminders editable.
- Allow users to snooze, reschedule or dismiss without penalty.
- Protect user privacy.
- Apply accessibility standards to every interface.
- Preserve existing working functionality.
- Do not introduce medical diagnosis or treatment advice.

## Brand

- Warm taupe
- Baby blue
- Soft grey
- Restrained gold accents
- Calm, uncluttered layouts

## Development

- Read relevant files in `/docs` before implementing features.
- Reuse existing components where practical.
- Do not duplicate services or data models.
- Add tests for new behaviour.
- Explain destructive changes before making them.
- Never commit secrets or credentials.
